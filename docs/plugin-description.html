Package, publish, debug and monitor your Azure Service Fabric applications without leaving JetBrains Rider.

Visual Studio has always shipped first-class tooling for Service Fabric. This plugin brings the everyday workflow to Rider: right-click your .sfproj, publish to your local cluster, hit Debug and land on your breakpoints in every service.

Features

  • Package – builds the application package with the right configuration and platform, with a live console and cancellation.
  • Publish – publish dialog with profiles, upgrade / overwrite options and parameters; runs Deploy-FabricApplication.ps1 for you.
  • Run & Debug – a Service Fabric Application run configuration (auto-created). Debug deploys, then attaches the .NET debugger to every service process: actors, stateless and stateful services.
  • Safe while debugging – Run/Debug are disabled during a debug session; Publish and Clean warn you and stop the sessions first.
  • Clean – removes the application and its type from the local cluster, runs MSBuild Clean and deletes pkg. Rider's own Build › Clean removes the application from the local cluster too, like Visual Studio.
  • Edit Versions – edit application, service and package versions in one dialog, with automatic roll-up; a single undo restores everything.
  • Manifest IntelliSense – completion and validation in ApplicationManifest.xml, ServiceManifest.xml, Settings.xml and parameter files, from the SDK schemas.
  • Live cluster health – status bar widget with the local cluster state and each application's health, same colors as Service Fabric Explorer, an orange starting state, and a notification when your application is really ready.
  • Environment check – detects the SDK, the PowerShell module and the local cluster, and tells you what is missing.
  • Start / Stop local cluster – start or stop the local development cluster from the Service Fabric menu (UAC prompt only when needed).

Getting started

  1. Open a solution containing a Service Fabric application project (.sfproj).
  2. Right-click the project › Service Fabric (right after Advanced Build Actions).
  3. Pick Publish…, or use the auto-created run configuration and press Debug.
  4. Watch the status bar: orange while the services start, green when the application is ready.

Settings: Settings › Tools › Service Fabric.

Requirements: Windows, the Azure Service Fabric SDK and a local development cluster. To debug services on the local cluster, run Rider as administrator (same as Visual Studio).
